Privacy Policy

Test Recorder Chrome Extension — Last updated: March 2026

Overview

Test Recorder is a browser extension that records your interactions (clicks, typing, scrolling, and navigation) on web pages and exports them as a JSON file in the Chrome DevTools Recorder format. The extension is a local utility — it does not collect, transmit, or store any data outside your browser.

Data collection

This extension collects no personal data. Specifically:

  • No data is sent to any external server or third party.
  • No analytics, crash reporting, or telemetry of any kind is used.
  • No user accounts, sign-ins, or identifiers are required or created.

How recorded data is handled

While a recording is active, interaction events (element selectors, input values, scroll positions, and page URLs) are held in the extension's background service worker memory. This data is:

  • Never written to chrome.storage or any persistent store.
  • Never transmitted over the network.
  • Discarded automatically when the extension is stopped or the browser is closed.
  • Only exported when you explicitly click Copy to Clipboard or Download JSON.

Permissions used

  • activeTab — reads the active tab's URL and title to create the opening navigate step.
  • scripting — runs a one-time script to read the window dimensions for the setViewport step.
  • tabs — detects URL changes during recording to insert navigate steps, and relays state changes to the content script.
  • host_permissions (<all_urls>) — allows the content script to be injected on whichever page you choose to record.

Third-party services

None. The extension contains no third-party code, tracking pixels, or remote resources.

Changes to this policy

If the extension's data practices ever change, this page will be updated and the "Last updated" date above will reflect the change.
